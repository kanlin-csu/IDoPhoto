🌐 **線上立即使用**：[https://idophoto.kanlin.org](https://idophoto.kanlin.org)

## 🌟 簡介

**IDoPhoto** 是一款專為證件照排版與超商 4x6 吋沖印設計的純靜態 Web 工具。
免安裝軟體、免註冊，所有圖片運算皆在您的瀏覽器本機端完成，完全不需要上傳到任何伺服器，100% 保障個人肖像與生物特徵隱私。

* **雙關命名寓意**：`ID Photo (證件照)` + `I do photo (交給我做證件照)`

---

## ✨ 核心特色

1. **標準規範對齊輔助線**
   - **2 吋護照/身分證**：外交部規範「頭頂至下巴 3.2 ~ 3.6 公分」範圍對齊帶。
   - **2 吋半身照/健保卡**：適合學生證、履歷表。
   - **1 吋證件照**：駕照、國家考試、專業證照規格。
   - 包含：臉部橢圓參考框、中心垂直中軸線、雙眼水平基準線。

2. **精準互動調整**
   - 滑鼠任意拖曳平移 (Pan)
   - 滾輪 / 滑桿等比縮放 (Zoom)
   - 角度旋轉補正 (Rotate ±25°，微調歪頭)
   - 曝光亮度與對比度微調

3. **4×6 吋沖印排版 (真 300 DPI 高畫質輸出)**
   - **2 吋 × 8 張**（標準大頭照排版）
   - **1 吋 × 10 張**（駕照與常用小證件）
   - **經典混搭 (2 吋 × 4 張 + 1 吋 × 4 張)**（一次搞定兩種規格）
   - 自動生成十字裁切對齊線 (Corner Marks) 與淡灰防溶底邊框

4. **超商沖印神助手**
   - 產生之 1800×1200 像素圖檔，可直接存到隨身碟或上傳至 7-11 ibon / 全家立可得機台，選擇「4×6 吋生活照」列印，單張只需 4 ~ 6 元！
   - 同時支援單張高解析度電子檔下載（線上換發護照、求職履歷使用）。

5. **真 300 DPI 實體標記與 20mm 校對尺**
   - 匯出圖檔時直接改寫二進位 JFIF 標頭，注入真 300 DPI 密度標籤，避免家用印表機尺寸錯亂。
   - 排版相紙底部內建 20 mm 實體校正標尺，印出後拿直尺即可驗證沖印精確度。

6. **行動裝置原生適配 (Mobile RWD)**
   - 支援單指拖曳平移、雙指捏合縮放 (Pinch-to-zoom)。
   - 行動端雙頁籤工作介面，並支援呼叫手機相機即拍即修。

7. **透明去背圖自動套用白底**
   - 支援由手機相簿（iPhone / Android 原生「長按 1 秒去背」）或專業工具（如 Canva 線上去背）產生之透明 PNG。
   - 匯入本系統後自動套用標準證件照純白底（#FFFFFF），無縫銜接頭部與雙眼對齊排版。

8. **PWA 支援（免商店即可安裝至手機桌面）**
   - 完整支援 Progressive Web App，支援點擊「安裝 App」或「加入主畫面」。
   - 具備 Service Worker 離線快取，全螢幕獨立視窗運作，體驗比擬原生 App。

9. **SEO 與 AI 爬蟲最佳化 (GEO / LLM SEO)**
   - 內嵌完整 Schema.org JSON-LD 結構化資料 (`WebApplication`, `HowTo`, `FAQPage`)，利於 Google 與各大 AI 搜尋引擎（ChatGPT, Perplexity, Copilot）精確檢索引用。
   - 支援 Open Graph 1200×630 品牌社群預覽卡片與 Twitter Cards。
   - 提供標準 `robots.txt`、`sitemap.xml`，以及專為大語言模型設計的 `llms.txt`。
   - 網頁內建語意化常見證件規格速查表與常見問答 (FAQ)。

## 🚀 快速開始

本專案為 **100% 純靜態網站 (Pure Static Web)**，無須安裝 Node.js、Python 或任何依賴套件。

### 方法一：直接點擊開啟
1. 下載或複製本專案。
2. 在檔案總管中對著 `index.html` 連按兩下滑鼠左鍵，使用 Chrome、Edge、Safari 或 Firefox 等瀏覽器開啟即可開始使用。

### 方法二：透過任何 HTTP 伺服器啟動（可選）
```bash
# 使用 Python 快速預覽
python -m http.server 8080

# 或使用 Node.js npx
npx serve .
```
開啟瀏覽器訪問 `http://localhost:8080` 即可。

## 🖨️ 超商沖印重要技巧

1. 請務必選擇機台上的**「4×6 吋相片沖印」**（一般生活照方案，請勿點選機台內的證件照專區，價格相差甚鉅）。
2. 在版面設定中選擇**「符合照片 / 滿版列印」**，關閉自動裁切，確保 1:1 精確物理尺寸輸出。
3. 印出後拿尺對齊四周細灰裁切十字線，用美工刀或剪刀裁切即可。
